# Sinchana & Vinay – Premium Digital Wedding Invitation Website 💍
### ಸಿಂಚನ ಕೆ.ಪಿ. & ವಿನಯ್ ಹೆಚ್.ಜೆ. • Bohemian Luxury Wedding Stationery

A complete, luxury digital wedding invitation website built with **React**, **Vite**, **Tailwind CSS**, and **Framer Motion**. Designed as an editorial wedding stationery suite combining modern Bohemian luxury with traditional Kannada wedding culture.

## 📁 Suggested Folder Structure

```
src/
  components/
    OpeningAnimation.jsx        # First screen letter-by-letter & 3D envelope opening
    EnvelopeAnimation.jsx       # 3D folding envelope component
    HeroSection.jsx             # Main stationery hero card
    Countdown.jsx               # Live countdown timer (22 Nov 2026, 9:30 AM)
    WeddingEvents.jsx           # Pre-Wedding Function & Wedding Ceremony cards
    PhotoGallery.jsx            # Masonry gallery & full-screen lightbox
    VenueSection.jsx            # Venue details & Google Maps
    MusicPlayer.jsx             # Floating background wedding instrumental player
    LanguageToggle.jsx          # English / Kannada switcher
    Footer.jsx                  # Minimal floral footer
    TraditionalMotifs.jsx       # Krishna flute, peacock feather, lotus, kalasha
    BotanicalDecorations.jsx    # Pampas grass, dried palms, wax seal, floating petals
  config/
    weddingDetails.js           # Single editable configuration file
  translations.js               # English and Kannada localization
  App.jsx                       # Root application orchestrator
  main.jsx                      # React entry point
  index.css                     # Paper textures, custom scrollbars, animations
```

## 🚀 Running the Project

### 1. Start Development Server
```bash
npm run dev
```
Open **`http://localhost:5173`** in your browser.

### 2. Build for Production
```bash
npm run build
```
Creates an optimized static bundle in `dist/`.
